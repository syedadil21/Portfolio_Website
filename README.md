# Syed Adil — Portfolio

Personal portfolio website built with Next.js 16, Tailwind CSS 4, Three.js, and Framer Motion.

**Live:** [syedadil21.vercel.app](https://syedadil21.vercel.app)

## Features

- 3D geometric terrain background (Three.js + React Three Fiber)
- Typewriter hero with cycling titles
- Accordion experience section
- Project cards with category filters and case study links
- Detailed case study pages with image carousels
- AI chatbot powered by Groq (Llama 3.3 70B)
- Contact form via Web3Forms
- Scroll-tracked navbar with active section highlighting
- Fully responsive, dark theme

## Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Styling:** Tailwind CSS 4
- **3D:** Three.js + React Three Fiber
- **Animations:** Framer Motion, CSS keyframes
- **AI Chat:** Groq API (Llama 3.3 70B)
- **Contact:** Web3Forms
- **Icons:** react-icons
- **Deployment:** Vercel

## Getting Started

```bash
npm install
cp .env.local.example .env.local  # Add your GROQ_API_KEY
npm run dev
```
